# Ergebnisse

Dieser Ordner ist fuer deine eigenen Testprotokolle und den Plot vorgesehen.
`delay_referenz.png`, falls mit `--referenz` erzeugt, ist ausdruecklich ein Referenzplot.
Vorbereitende Entwicklerpruefungen liegen in `tmp/`, nicht als erledigte Nutzeraufgaben hier.
Die Tests pruefen die stationaere Addition. Gate-Laufzeiten werden dadurch nicht nachgewiesen.
