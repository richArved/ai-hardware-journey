## Einheitliche Ablage

| Ordner | Inhalt |
| --- | --- |
| `zusammenfassungen/` | Erklärungen, Lernblätter und Cheatsheets |
| `aufgaben/` | Aufgabenblätter und Abschlussarbeiten, auch bereits annotierte PDFs |
| `loesungen/` | Musterlösungen |
| `quellen/` | Bearbeitbare LaTeX-Dateien der PDFs |
| `praxis/` | Logisim- und Digital-Schaltungen |

Es werden nur Ordner angelegt, für die Materialien vorhanden sind. Zusammengehörige Python-Projekte und SPICE-Übungen behalten ihre Arbeitsverzeichnisse und Befehle. Simulationsergebnisse liegen bei der jeweiligen Übung, meist in `results/`.

Die Tages-READMEs verlinken alle Lernmaterialien. Bei Tag 6 ist `Tag06_Aufgaben_Neu.pdf` das neue vollständige Aufgabenblatt; das bisherige Blatt bleibt mit deinen Notizen erhalten.
